# MenteActiva Senior

Aplicacion web responsive para adultos mayores con ejercicios de memoria y estimulacion cognitiva.

## Tecnologias

- HTML
- CSS
- JavaScript puro

## Actividades incluidas

- Frase invertida
- Cuadrado magico
- Palabra oculta
- Secuencia de palabras
- Relacion por categoria
- Refran incompleto
- Conteo mental

## Funciones de accesibilidad

- Texto base grande
- Botones amplios
- Pistas para cada ejercicio
- Lectura en voz alta con `speechSynthesis`
- Dictado de respuesta cuando el navegador lo soporte

## Uso

1. Abra `index.html` en cualquier navegador moderno.
2. Presione `Comenzar`.
3. Elija un nivel de dificultad.
4. Seleccione una actividad.

## Estructura

```text
mente-activa-senior/
├── index.html
├── README.md
├── css/
├── js/
├── data/
├── assets/
└── docs/
```

## Nota

Los archivos de `data/` se incluyen como referencia del contenido del proyecto. La aplicacion utiliza datos locales en JavaScript para asegurar que funcione al abrir `index.html` directamente desde el navegador sin configuraciones adicionales.
