# Documentacion inicial

## Introduccion

MenteActiva Senior es una aplicacion web educativa pensada para apoyar ejercicios de memoria y estimulacion cognitiva en adultos mayores mediante actividades simples, visibles y faciles de usar. La aplicacion incluye varias actividades, pistas de apoyo y herramientas de voz para facilitar una experiencia mas accesible.

## Problema identificado

Muchas aplicaciones digitales presentan interfaces complejas, texto pequeno o exceso de elementos visuales, lo que dificulta su uso por parte de personas mayores. Ademas, no siempre ofrecen actividades breves de entrenamiento mental con instrucciones claras.

## Objetivo general

Desarrollar una aplicacion web responsive con ejercicios cognitivos accesibles, simples y funcionales para adultos mayores.

## Objetivos especificos

- Implementar actividades de memoria con validacion automatica.
- Incorporar niveles de dificultad facil, medio y dificil.
- Mantener una navegacion clara con botones grandes y visibles.
- Mostrar retroalimentacion inmediata y puntaje acumulado.
- Permitir el uso directo desde el navegador sin instalar software adicional.

## Publico objetivo

Adultos mayores que deseen realizar ejercicios de memoria de forma guiada, simple y amigable desde celular, tablet o computadora.
