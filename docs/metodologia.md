# Metodologia

## Explicacion de Prompt-Driven Development

Prompt-Driven Development es una metodologia de desarrollo donde los requerimientos iniciales se formulan mediante instrucciones detalladas en lenguaje natural. A partir de esos prompts se construyen la estructura, las funcionalidades y la documentacion del proyecto.

## Por que se eligio

Se eligio porque permite traducir necesidades funcionales y de accesibilidad de manera directa, ordenada y rapida. Tambien ayuda a documentar claramente el origen de cada parte del sistema y facilita iteraciones futuras.

## Como se aplico en el proyecto

- Se partio de un prompt inicial con requisitos funcionales, de accesibilidad y de estructura.
- Se definieron las actividades principales a implementar: frase invertida, cuadrado magico y palabra oculta.
- Se organizo el proyecto en carpetas separadas para estilos, scripts, datos y documentacion.
- Se priorizo un desarrollo simple con HTML, CSS y JavaScript puro para asegurar facilidad de mantenimiento.
- Se incorporaron decisiones de diseno enfocadas en legibilidad, contraste, tamano de fuente y navegacion sencilla.
