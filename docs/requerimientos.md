# Requerimientos

## Requerimientos funcionales

- La aplicacion debe mostrar una pantalla de inicio con titulo, descripcion y boton para comenzar.
- Debe existir un menu principal con varias actividades cognitivas.
- Cada actividad debe ofrecer niveles facil, medio y dificil.
- El sistema debe validar las respuestas del usuario.
- Debe existir retroalimentacion clara para respuestas correctas e incorrectas.
- El sistema debe acumular y mostrar puntaje actual.
- Deben existir botones para repetir ejercicio, cambiar de actividad y volver al menu.
- Cada actividad debe incluir una pista de ayuda.
- La aplicacion debe ofrecer lectura por voz del contenido principal.
- La aplicacion debe permitir dictado de respuesta cuando el navegador lo soporte.

## Requerimientos de accesibilidad

- El tamano base del texto debe ser de al menos 18 px.
- Los botones deben ser grandes y faciles de pulsar.
- El contraste entre fondo y texto debe ser alto.
- Las instrucciones deben redactarse con lenguaje simple.
- La interfaz no debe saturar la pantalla con informacion innecesaria.
- El diseno debe adaptarse a celular y tablet.

## Requerimientos no funcionales

- El proyecto debe desarrollarse sin frameworks ni librerias externas.
- Todo debe funcionar abriendo `index.html` directamente en el navegador.
- El codigo debe ser simple, ordenado y entendible.
- La estructura de carpetas debe mantenerse segun lo solicitado.
